# Unear Admin

Administration dashboard for Unear, built with Vite, React, and TypeScript.

## Local development

Requires Node.js and npm.

```sh
npm install
npm run dev
```

## Tech stack

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS

## Scripts

- `npm run dev` — start dev server
- `npm run build` — production build
- `npm run preview` — preview production build
- `npm run lint` — run ESLint
- `npm test` — run tests
